# AI Engineering Roadmap

My hands-on journey from Python fundamentals to GenAI engineering.
This repo is my learning log. My finished projects are in my other pinned repos.

## Progress

| Folder | What's inside | Status |
|---|---|---|
| `00_python_basics` | Syntax, control flow, OOP | Done |
| `01_math_and_numpy` | Linear algebra, vectorised NumPy | Done |
| `02_pandas_and_eda` | Pandas, visualisation, Titanic EDA | Done |
| `03_classical_ml` | Linear and logistic regression, decision trees, random forests, SVM, k-NN, k-means, evaluation metrics | Done |
| `04_sql` | Joins, aggregation, subqueries | Done |
| `05_problem_solving` | Coding challenges and applied exercises | Ongoing |

## Stack

Python 3.11+, NumPy, Pandas, Matplotlib, Seaborn, scikit-learn, SQL

SQL practice uses the free Chinook sample database (not included in the repo, download it separately).

## Run it

```bash
git clone https://github.com/anjana-dev-code/ai-engineering-roadmap
cd ai-engineering-roadmap
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```
